WebRTC Peer-to-Peer Multiplayer (GitHub Pages)

Connect two browsers directly over WebRTC DataChannels. Host controls Team 1; Peer controls Team 2.

Option 1: Quick Room Code (PeerJS)

Enter a custom room code (or leave blank to generate one) and share it with your opponent.

Option 2: Zero-Server SDP Token Copy/Paste

1. Host clicks Create Offer & sends token to Peer.
2. Peer pastes token, clicks Create Answer & sends back.
3. Host pastes answer & clicks Complete.
